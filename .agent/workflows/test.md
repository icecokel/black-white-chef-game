# Game Verification Workflow

이 워크플로우는 브라우저 에이전트를 사용하여 게임의 핵심 기능(라운드 진행, 심사, 결과 산출)이 정상 동작하는지 테스트합니다.

## 0. 중요 원칙 (Critical Rules)

**이 워크플로우 실행 시 다음 규칙을 절대적으로 준수해야 합니다.**

1. **언어 정책**: 모든 문서, 보고서, 사용자 소통은 **반드시 한글**로 작성한다.
2. **코드 수정 금지**: 이것은 테스트 작업이므로, **절대 소스 코드를 수정하지 않는다.**
3. **보고 중심**: 테스트 결과와 버그는 `review_report.md` 등의 **문서 파일로 보고**하는 것을 원칙으로 한다.
4. **예외적 수정**: 테스트 진행 자체가 불가능한 치명적 버그(Blocking Bug)일 경우에만 예외적으로 수정하되, **반드시 사전에 사용자의 승인**을 받아야 한다. 승인이 없다면 절대 수정하지 않는다.

## 1. 환경 준비

테스트를 위해 43000 포트를 초기화하고 개발 서버를 실행합니다.

// turbo

1. `lsof -t -i :43000 | xargs kill -9` 명령어로 기존 프로세스 종료
   // turbo
2. `npm run dev -- --port 43000` 명령어로 백그라운드 서버 실행 (충분한 대기 시간 필요)

## 2. 브라우저 테스트 실행

`browser_subagent`를 사용하여 다음 시나리오를 수행합니다.

### 시나리오

1. **접속**: `http://localhost:43000/black-white-chef-game/` 이동
2. **Round 1 (흑수저 결정전)**:
   - '서바이벌 시작' 진입
   - '자동 선택'으로 20명 선택
   - '심사 시작' 후 완료 대기 (20명 생존 확인)
3. **Round 2 (1vs1 흑백 대전)**:
   - '2라운드 시작' 진입
   - 2개의 매치에 대해 각각 흑수저/백수저 쉐프 선택 (My Pick)
   - '결과 확인' 클릭
   - 하이라이트 매치(4개) 순차 진행 (Next 버튼 클릭)
   - 최종 생존자 요약 화면 도달 확인
4. **Round 3 (흑백 팀전)**:
   - '3라운드 시작' 진입
   - 팀 선택 (예: 흑수저 팀)
   - 1차전(100인), 2차전(50인), 3차전(10인) 순차 진행
   - **중요**: 2차전, 3차전 진행 시 심사위원 버튼의 텍스트와 실제 하단 심사위원 수(점 개수)가 일치하는지 확인
   - 최종 승리 팀 결과 화면 확인

### 스크린샷 캡처 포인트

- Round 1 완료 시점
- Round 2 결과 요약 화면
- Round 3 2차전/3차전 진행 화면 (버그 검증용)
- 최종 승리 화면

## 3. 리포트 작성

테스트 결과를 바탕으로 `walkthrough.md` 또는 `review_report.md`를 작성/갱신합니다.

- 각 라운드별 Pass/Fail 여부
- 발견된 특이사항 (예: 심사위원 수 불일치 등)
- 캡처된 스크린샷 포함
